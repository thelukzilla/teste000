# Project_srmen

Protótipo mobile-first de um micro SaaS gamificado de desenvolvimento pessoal masculino, focado em saúde mental leve, autoestima, disciplina, rotina e estoicismo prático.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Como rodar

```bash
npm install
npm run dev
```

A aplicação usa apenas dados mockados e estado local. Não há backend, autenticação, banco de dados ou pagamento nesta versão inicial.

## Telas do protótipo

- Dashboard inicial
- Trilha Estoicismo Prático
- Lição de fundamentos
- Exercício prático
- Quiz
- Reflexão
- Missão do dia
- Progresso
- Conteúdos / biblioteca
- Perfil
